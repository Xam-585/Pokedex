# 🧩 Pokédex Web App

A responsive Pokédex application built with vanilla JavaScript, HTML, and CSS.  
The app fetches data from the PokéAPI and allows users to browse, search, and view detailed information about Pokémon.

---

## 🚀 Features

- 🔍 **Search Function** – Find Pokémon by name in real time
- 📄 **Pagination** – Navigate through all available Pokémon
- 📊 **Detailed View** – View stats, types, abilities, height, and weight
- 🎨 **Dynamic Styling** – Cards styled based on Pokémon types
- ⏳ **Loading Screen** – Visual feedback while fetching data
- 💾 **Local Storage** – Cached data for faster reloads
- 📱 **Responsive Design** – Optimized for desktop and mobile

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 (Flexbox & Grid)**
- **JavaScript (ES6+)**
- **PokéAPI** (https://pokeapi.co/)
